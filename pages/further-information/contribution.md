Please first refer to the [NIST Internal Report 8588 "A Community-Driven Differential Privacy Registry"](https://csrc.nist.gov/pubs/ir/8588/ipd) for proposed governance and community standards for contributing to this project.
**The public comment period is open through November 14, 2025. NIST invites the public to comment on the plan and especially welcomes contributions that will help maximize the value of the DP Registry.**

Under those terms, please refer to the current repositories for the Registry Data and Registry UI for details on how to contribute issues or pull requests to either resource.
